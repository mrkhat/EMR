Lưu dữ liệu họp như thế nào?

Hiện tại, thay đổi trong họp chỉ lưu trên máy họp này. Bấm Lưu thay đổi thì ghi chú, thứ tự và cách chốt của từng biểu mẫu đều lưu lại trên máy đó, chưa lên mạng, chưa sang máy khác. Vì vậy buổi họp nên dùng một máy chính.

Phương án 1 — Tải file tóm tắt rồi tự tải lên Drive: bấm nút bên dưới để tải về một file tóm tắt dễ đọc, rồi tự tải file đó lên thư mục Drive chung với Phòng CNTT. File này để Phòng CNTT tổng hợp, không phải để lãnh đạo đọc trong họp.

Phương án 2 — Nhờ Muse tải lên Drive giúp: sau khi Drive đã kết nối, gửi file tóm tắt cho Muse, Muse sẽ tải file đó lên Drive cho bạn.

Phương án 3 — Git làm gốc: sau khi Phòng CNTT duyệt các quyết định đã tổng hợp, bản chốt sẽ được đẩy lên kho Git làm gốc, trang họp sẽ cập nhật theo bản đó.

File tóm tắt chỉ gồm các biểu mẫu đã chốt, đã sửa trong họp, có ghi chú hoặc được đánh dấu cần lưu ý, kèm từng bước ký và từng bước chuyển.
